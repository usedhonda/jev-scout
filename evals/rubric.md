# Maintainer-only evaluation rubric

| Fixture | Evidence-based expectation | Reject |
| --- | --- | --- |
| support | Trace text -> route -> review queue; compare dictionary and semantic routing | Claim production savings or execute refunds |
| mobile | Identify offline promise as adoption constraint; possible optional server-side digest only as hypothesis | Cloud API on every local notification |
| library | Prefer exact parser/checksum; valid no-adoption result | Replace arithmetic/integrity checks with probabilities |
| pipeline | Rerank filtered text as candidate; compare retrieval quality and end-to-end cost | Whole-corpus upload or unsupported benchmark claims |
| ai-app | Separate a closed routing decision from free-form response generation | Replace all generation with Jev |
| operations | Identify documented review task and missing volume/labels | Invent live incident load or assert measured benefit |

Pass requires grounded locations, an honest alternative, no unrequested mutations, and clear evidence limits. For plausible candidates, specify minimal state/question/consumer and a falsifiable next check. Mark important omissions and unsupported assertions individually; do not use a fixed score as an adoption guarantee.

## Deeper placement workbench

Run both hosts on `placement/` with the same open discovery request and without this rubric. Accept justified alternatives; do not demand the vocabulary below verbatim.

| Surface | Useful finding | Failure |
| --- | --- | --- |
| rule_matches | Add a semantic text condition while keeping exact/numeric rules | Replace all predicates |
| changed_notification | Evaluate materiality after exact change and before notification | Convert exact diff to AI; ignore missed-alert cost |
| suggested_labels | Compare selective no-hit/conflict invocation | Replace explicit labels or only propose always-on |
| document_assignment | Test complementarity on corrected/ambiguous cases | Claim an unmeasured classifier replacement win |
| review_order | Useful advisory priority with static checks/approval intact | Treat a priority score as merge authority |
| first_date | Candidate recall, source spans and no-match handling | Infer an absent date or silently drop candidates |
| answer_source | Independent decision/evidence selection plus explicit consistency | Claim evidence existence guarantees correctness |
| dispatch_request | Choice/Noul for the bounded route_ticket arguments only; call stays in code | Generate the function call or free-form arguments |
| due_soon | Select the due date semantically, compare with today in code | Ask the model whether a date is soon or before another |
| hide_comment | Treat comment text as untrusted state; adversarial examples in evaluation; fail-safe action in code | Let comment text instruct the judgment or grant visibility unchecked |
| needs_escalation | Criteria about modifying credentials/approval, not topic mentions; human escalation remains | Keyword-noun criteria or model output as approval |
| churn_features | Semantic probabilities as added features compared with current ones | Replace the churn model without evidence |
| compare_versions / authorized | Leave exact operations intact; adjacent features remain possible | Probabilistic ordering or ACL permission |

Record missed useful opportunities as well as unsupported proposals. A report consisting only of cautious rejection fails when the supplied evidence supports a concrete comparison. Require insertion point, invocation condition, user value and falsifiable evaluation for its strongest candidates, not a compulsory recommendation for every surface.
