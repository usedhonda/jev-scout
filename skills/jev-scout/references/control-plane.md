# Control-plane discovery

Use this reference only when the repository already controls an iterative process, expensive work, retained state, a partial stream, or candidate generation. The opportunity is not merely another classifier: a small semantic judgment may change **what the system computes next**. Trace input/current state -> existing control decision -> consumer and cost of a wrong decision before proposing it. Keep placement (sidecar, gate, advisory, replacement) separate from decision role.

| Existing seam | Possible bounded Jev role | Keep in code and compare against |
| --- | --- | --- |
| Fixed retrieval rounds or hit-count stopping | Judge whether accumulated evidence suffices for the question; stop or retrieve again | Hard round/time/spend cap, retrieval, source verification, answer/citation checks; compare fixed rounds and a simple stopping heuristic on final-answer quality, premature stops, calls and whole-pipeline latency |
| Age/size-based conversation or tool-log compaction | Select which tool calls/results retain full content, a pointer, or neither; do not rewrite surviving evidence | Call/result pairing, pinned constraints/recent turns, token budget, recoverability and fallback; compare downstream task success, fact loss, re-runs, prompt-cache effects and total cost, not compression ratio alone |
| Expensive test matrix or regeneration loop | Estimate semantic impact or whether another attempt has value after exact eligibility checks | Dependency/touched-test selection, required security/smoke checks, runner and retry/idempotency caps; compare missed failures and end-to-end compute cost. Unknown/provider failure must not silently skip required tests |
| Claim-bearing names, comments, tests or specs beside executable behavior; repeated agent checkpoints | Flag a possible semantic contradiction or lack of progress toward an explicit acceptance condition | Syntax/types/static checks, source spans, permissions, task authority and human confirmation; measure false flags and useful work wrongly marked as drift. A signal does not grant stop or approval authority |
| Partial speech/text stream with a fixed debounce or silence timer | Judge whether the meaning is complete enough to commit now | ASR/VAD, minimum pause, sequence freshness, cancellation and hard latency deadline; compare premature commits and user-perceived delay. Do not add a remote round trip to a hard real-time control cycle |
| Search tree, optimizer, candidate generator, or large bounded output | Score/choose an exploration prior, evaluate a generated candidate, or factor independent typed axes before code composes them | Legal moves, state transitions, exact costs, geometry/parser constraints, stopping budget and final acceptance; compare ordinary heuristics, deterministic metrics, an existing judge or weighted table on held-out outcomes |

For cache reuse, a semantic judgment may ask whether a **still technically valid** artifact remains useful. It must not replace hash/version/schema invalidation or a hard TTL. For exact solvers, do not replace a proof of completion with a probability. For a generated DSL or finite grammar, repeated Choice is at most an experimental preference over parser-enumerated legal next symbols; ordinary free-form text generation is not a default Jev opportunity.

If a generator optimizes against Jev's score, check for reward hacking with held-out human judgment and fixed independent checks. An attractive rubric score is not proof that the artifact satisfies the user's actual requirement.

Check dependencies between proposed judgments. Independent typed questions can share a request; if one answer changes another's candidate set, use a subsequent request or keep the dependency in code. A candidate is worth testing only if the relevant state is available, the added service can fit the latency/privacy budget, and a cheap deterministic alternative does not already provide the needed behavior. Code, transcripts and tool logs may be sensitive: an available key does not authorize sending them to the API.

Examples at fixed source revisions illustrate topology, **not** general performance: [selective tool-history retention](https://github.com/tamaratran/fast-jev-compaction/blob/e3f262a7f4d42bd8dd32ced30d26176f7cb545b0/README.md), [test selection](https://github.com/mizchi/jev-test-filter/blob/01319cdc2bb897a91b90c5c1685359332a66bc21/README.md), and [semantic contract checks](https://github.com/mizchi/jev-lint/blob/fc2e1ad47ccf502d43dc091e695bcb41bcec9e31/README.md). Treat published measurements as author-reported until independently reproduced; do not transfer their thresholds, latency or savings to another repository.
